# SparkScale Marketing

SparkScale Marketing is a polished marketing website built for a digital growth and branding agency. The site is designed to present services, showcase trust signals, highlight process and results, and convert visitors into leads through a strong content-first landing experience.

## Live Site

[sparkscale-marketing.vercel.app](https://sparkscale-marketing.vercel.app)

## Features

- Full marketing website layout with multiple sections
- Strong hero, services, process, work, team, pricing, FAQ, and contact flow
- Responsive design for desktop, tablet, and mobile
- Scroll reveal animations and interactive counters
- Testimonial carousel
- Mobile navigation menu

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Vercel for deployment

## Files

```text
sparkscale-marketing/
|-- index.html
|-- styles.css
|-- script.js
`-- image assets
```

## Run Locally

Because this is a static website, you can open `index.html` directly in a browser or serve it with any static server.

## Project Goal

This project focuses on frontend design, brand presentation, responsive layout, and conversion-oriented website structure. It is a good representation of landing page and marketing-site design work.
